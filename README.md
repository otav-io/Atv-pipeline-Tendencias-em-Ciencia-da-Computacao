# 🐒 Qual Macaco Você Seria? 🦧

Um quiz interativo divertido criado com **HTML, CSS e JavaScript puro** para descobrir qual macaco você seria!

## Sobre o Projeto

Este é um quiz interativo com 20 perguntas divertidas que descobrem qual tipo de macaco representa sua personalidade. O projeto inclui:

- ✅ Deploy automático com GitHub Actions

## 🚀 Como Usar

1. Clone o repositório
2. Abra o arquivo `index.html` no seu navegador
3. Responda as 20 perguntas
4. Descubra qual macaco você seria!

## 🔄 GitHub Actions Pipeline

O projeto possui uma pipeline automatizada que:

1. ✅ Valida o código HTML, CSS e JS
2. ✅ Faz deploy automático no GitHub Pages
3. ✅ Executa a cada push na branch `main`

### Arquivos da Pipeline

```
.github/workflows/deploy.yml
```
